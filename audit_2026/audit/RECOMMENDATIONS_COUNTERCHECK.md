## Part 2 — The "risk-aware adaptive preprocessing + reliability-weighted KD" candidate (§5 of the brief)

| # | Recommendation / question | Rating | Evidence and reasoning | Better alternative |
|---|---|---|---|---|
| 5.1 | Estimate conditional detection risk r̂_a(x) without labels at inference | **PARTIALLY SUPPORTED** (feasible, not novel) | Label-free per-frame mAP prediction exists (Rahman et al. 2020, B10; PCR, ICCV 2025, B11). Training targets are legitimate: per-image detection loss or per-image AP of f(a(x)) on the *training/validation* split with labels, regressed from cheap features. Calibration on rare fog/rain scenes is **UNTESTED** and, with no weather-labelled thermal data in the project, cannot be tested on FLIR. | If pursued, use the oracle-headroom analysis first (5.5); only build r̂ if headroom exists. |
| 5.2 | Is estimating r̂ for all actions more expensive than running them? | **SUPPORTED as a concern** | T07 (RTX 2080 Ti, fp32, batch 1, 512²): student 25–30 ms; gamma is ~free; LSRB+LCN is a few ms. Running all three enhancers plus three detector passes (~90 ms) and picking the best by a confidence proxy is the obvious "run them all" baseline; a router must beat it on accuracy *and* cost. A router that needs detector features to estimate r̂ already pays most of the detector cost. | Report routing time separately; include the run-all + confidence-max baseline (B6). |
| 5.3 | Does enhancement improve detection, or only aesthetics; can it delete weak evidence? | **UNTESTED** and the central empirical question | Gamma is a global monotone map; it cannot create edges but can compress contrast where the object sits (T08 shows the rule keys on *mean* only: a low-contrast image with mean 0.5 is untouched, which is exactly the LWIR fog signature). LSRB is untrained; LCN is a local normaliser that amplifies noise in flat regions. Literature (B13, A-matrix §D) gives no evidence that any of these helps thermal detection. | Experiment B4 with an *oracle per-image action* defines the headroom; if headroom ≈ 0 the programme stops. |
| 5.4 | Is risk-gating distinct from task-driven enhancement / MoE routing? | **REFUTED as novelty** | IA-YOLO (B1), GDIP (B2), Jayaraman 2026 (B3), YOLO-DER (B4), CADENet (B5), Ye et al. 2024 (B6: RL action selection incl. "skip"), learning-to-defer (B12). The exact combination is unpublished, but each piece is, and a reviewer will say "GDIP with an argmin". | Do not frame as a new mechanism. |
| 5.5 | Define an oracle action for offline analysis | **SUPPORTED** (and promoted to the first experiment) | Oracle = per-image argmin over actions of the detector loss (or argmax of per-image AP) using labels; deployable only as an upper bound. | Make the oracle-headroom table the go/no-go gate (EXPERIMENT_MATRIX B4/B5). |
| 5.6 | Compare with a detector trained with weather augmentation / modern robust detector | **SUPPORTED** | Standard: augmentation (brightness/contrast/blur/noise) during training usually erases the gain of test-time enhancement; D3T (A8) and CGDet (A2) are stronger thermal baselines than anything in the repo. | B0/B3 in the matrix. |
| 5.7 | Is the pseudo-RGB teacher actually stronger or better calibrated than the student? | **UNTESTED; the most important unanswered question** | No teacher evaluation exists. The teacher weights are named like the stock COCO checkpoint. A COCO YOLOv8-L on CycleGAN pseudo-RGB of FLIR frames may be *weaker* than the thermal student (CycleGAN hallucinations; Borrow-from-Anywhere needed joint fine-tuning). Note that feature mimic does not require a strong *detector*, only useful features, so the right test is the teacher-input ablation, not the teacher's mAP. | Experiments B1/B2/B3 + teacher-input ablation (P1 in the matrix). |
| 5.8 | Data-processing inequality I(Y;G(X)) ≤ I(Y;X) | **SUPPORTED as a statement, REFUTED as a contribution** | True for the Markov chain Y → X → G(X) with deterministic (or any) G; says nothing about finite-sample estimators or about a *teacher's features* as a training signal (which is not inference on G(X)). | Background sentence at most. See `MATH_STAT_REVIEW.md` §2. |
| 5.9 | 2ε regret bound | **REFUTED as a contribution** | If |r̂_a(x) − r_a(x)| ≤ ε for all a, then r_{â}(x) ≤ r_{a*}(x) + 2ε; one line, standard in selective prediction / L2D (B12). Uniform ε is unrealistic for rare weather. | Background only; any real guarantee needs stated assumptions (see MATH_STAT_REVIEW §3). |
| 5.10 | Weather confounded with site/camera/time; causal interpretation of the gate | **SUPPORTED as a risk; UNTESTED** | FLIR ADAS v2 has no weather labels (C-table); any "weather" label would be derived from image statistics or video metadata, hence confounded with scene, time of day and AGC state by construction. UNIRI-TID / ZUT-FIR-ADAS / DENSE have real labels but different cameras and scenes. No causal identification is possible from FLIR alone. | If a weather claim is made, use real-weather sets and report per-sequence cluster bootstrap; treat "weather" as a *domain*, not a cause. |
